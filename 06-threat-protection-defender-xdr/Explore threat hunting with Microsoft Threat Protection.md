## Threat Hunting with Microsoft Threat Protection Summary

### What is Threat Hunting:
- A **proactive security activity** to find hidden threats
- Targets threats that:
  - Aren’t detected by security tools
  - Are buried in large volumes of data
- Relies heavily on **human expertise + threat intelligence**

---

### Key Requirements:
- Comprehensive and searchable security data  
- Threat intelligence (attack patterns, indicators)  
- Established **baseline of normal behavior**  

---

### How Threat Hunting Works:
- Analysts define normal activity (baseline)
- Search for **anomalies or unusual behavior**
- Use queries to detect suspicious patterns
- Automate queries to continuously monitor threats

---

### Example Process:
1. Identify new vulnerability  
2. Research attack behavior  
3. Build baseline queries  
4. Detect deviations from normal activity  
5. Set alerts for suspicious matches  
6. Investigate findings  

---

## Microsoft Threat Protection Capabilities:

### Core Strength:
- Uses **Microsoft Intelligent Security Graph + AI/ML**
- Collects and analyzes large volumes of security data

---

### Coverage:
- Users  
- Endpoints  
- Email  
- Apps & cloud services  

---

### How It Works:
1. Collects data across Microsoft ecosystem  
2. Analyzes using AI, ML, and threat intelligence  
3. Generates alerts for suspicious activity  
4. Triggers automated investigation & remediation (AIR)  

---

### Key Features:
- Detects threats across environments  
- Differentiates **normal vs malicious behavior**  
- Automatically remediates threats (e.g., quarantine files)  

---

### Role of Human Analysts:
- Investigate advanced or hidden threats  
- Create custom queries and detection rules  
- Validate and refine results  
- Handle complex or novel attack scenarios  

---

### Benefits:
- ✅ Faster threat detection  
- ✅ Proactive defense approach  
- ✅ Scalable data analysis  
- ✅ Reduced manual effort with automation  
- ✅ Improved detection accuracy  

---

### Key Takeaway:
Threat hunting combines **human expertise + AI-driven insights** to proactively detect and respond to advanced, hidden threats that automated systems might miss.
