# Explore Team Insights in Microsoft Viva Insights

# Overview

Microsoft Viva Insights Team insights are designed for managers and team leaders who have direct reports.

Team insights provide:

- Team collaboration analytics
- Meeting habit insights
- Wellbeing indicators
- Productivity recommendations
- Suggested actions for managers

These insights help managers improve team culture, productivity, and employee wellbeing.

---

# What Are Team Insights?

Team insights are manager-focused insights generated from collaboration data.

Microsoft Viva Insights analyses:

- Emails
- Meetings
- Teams chats
- Calls
- Collaboration patterns

to provide managers with recommendations about team behaviours and work habits.

---

# Main Purpose of Team Insights

The goal of Team insights is to help managers:

- Build healthier team habits
- Reduce burnout
- Improve meeting culture
- Encourage focus time
- Strengthen team collaboration
- Improve employee wellbeing

---

# Important Privacy Principle

Managers cannot see personal collaboration habits of individual team members.

---

# Privacy Protection in Team Insights

Microsoft designed Team insights with strong privacy protections.

---

# Key Privacy Features

| Privacy Feature | Description |
|---|---|
| No individual monitoring | Managers cannot view personal employee activity |
| Aggregated insights only | Data is shown as group trends |
| Metadata analysis | Uses collaboration metadata |
| Privacy-protected analytics | Individual user behaviour is hidden |

---

# Important

Team insights are generated using:

- Activity data
- Collaboration metadata
- Aggregated workplace behaviour patterns

and NOT employee surveillance.

---

# Data Sources Used by Team Insights

Team insights use data from:

- Emails
- Meetings
- Calls
- Teams chats
- Collaboration activity

---

# Organizational Data Sources

Microsoft Viva Insights builds teams using either:

| Source | Description |
|---|---|
| Microsoft Entra ID | Default source |
| HR organizational data file | Uploaded by administrator |

---

# Important

Azure Active Directory (Azure AD) is now called Microsoft Entra ID.

---

# How Viva Insights Builds Teams

Viva Insights automatically builds a manager's team using organizational hierarchy data.

---

# Team Membership Rules

Your team only includes:

- Employees who directly report to you

based on:

- Microsoft Entra ID
OR
- Uploaded HR file

---

# Important Team Structure Rules

| Rule | Description |
|---|---|
| Direct reports only | No indirect reports included |
| Automatic creation | Teams generated automatically |
| No manual editing | Managers cannot edit team members |
| Requires organizational data | Team structure depends on HR/Entra data |

---

# Requirements for Team Insights

Managers must have:

- At least one direct report

Otherwise:

- Team insights will not be available.

---

# Why Accurate Organizational Data Matters

Organizations must regularly update:

- Microsoft Entra ID
OR
- HR data uploads

to ensure:

- Correct reporting structures
- Accurate team insights
- Updated collaboration analytics

---

# Weekly Data Refresh

When team membership changes:

- Viva Insights reflects updates in the following week's data refresh.

# Pinning Viva Insights in Teams (Desktop/Web)

## Steps

1. Open Microsoft Teams
2. Select the ellipsis (...) icon
3. Search for "Microsoft Viva Insights"
4. Open the app
5. Right-click the app icon
6. Select Pin

---

# Pinning Viva Insights on Mobile (iOS/Android)

## Steps

1. Open Teams
2. Select the ellipsis (...) icon
3. Open Viva Insights
4. Select Reorder
5. Drag the app icon
6. Select Done

---

# Uninstalling Viva Insights

## Steps

1. Open Teams
2. Select the ellipsis (...) icon
3. Find Viva Insights
4. Right-click the app
5. Select Uninstall
6. Confirm uninstall

---

# Turning Team Insights On or Off

Users can opt in or opt out of Team insights.

---

# Steps to Enable or Disable Team Insights

1. Select the ellipsis (...) icon
2. Open Settings
3. Select Team insights
4. Choose:
   - Opt in
   - Opt out
5. Select Save changes

# Team Meeting Habits

Team insights heavily focus on meeting culture and collaboration behaviours.

Managers are considered role models for workplace collaboration.

---

# Microsoft Research on Meeting Behaviour

Microsoft conducted studies showing that:

Managers who multitask during meetings often influence their teams to do the same.

---

# Example

If managers:

- Read emails during meetings
- Send messages during meetings

their employees are significantly more likely to develop the same habits.

---

# Definition of Multitasking

Microsoft defines multitasking in meetings as:

- Reading emails
- Sending emails
- Performing unrelated tasks during meetings

---

# Impact of Poor Meeting Habits

Poor meeting habits can lead to:

- Reduced focus
- Lower engagement
- Burnout
- Decreased productivity
- Poor collaboration culture
