# Explore Microsoft 365 Apps for Enterprise Functionality

---

# 📌 Overview

Microsoft 365 Apps for enterprise (formerly Office 365 ProPlus) is the downloadable desktop version of Microsoft Office included with many Microsoft 365 subscriptions.

The applications install locally on a user's device and provide full desktop functionality.

The Microsoft 365 license assigned to a user determines:
- Which apps they can install
- Which features they can access
- How many devices they can activate

---

# 🖥️ Applications Included

Microsoft 365 Apps for enterprise includes:

- Microsoft Word
- Microsoft Excel
- Microsoft PowerPoint
- Microsoft Outlook
- Microsoft Access
- Microsoft Publisher
- Microsoft OneNote
- Microsoft Teams

---

# 🍎 macOS Limitation

The following applications aren't included in Microsoft Office for Mac:

- Microsoft Access
- Microsoft Publisher

---

# 🚀 Click-to-Run Technology

Microsoft 365 Apps for enterprise uses:
- Click-to-Run deployment technology

---

# 📌 What Click-to-Run Does

Click-to-Run allows users to:
- Begin using applications before installation fully completes
- Stream installation in the background
- Reduce deployment time
- Improve update management

---

# 🌐 Internet Requirements

An Internet connection is required for:
- Initial installation
- Activation
- License validation
- Updates

---

# ❗ Important Licensing Requirement

Although the applications run locally:
- Users must connect to the Internet at least once every 30 days
- Microsoft validates the Microsoft 365 license automatically

Failure to validate may result in:
- Reduced functionality mode

---

# 💻 Local Installation Model

Microsoft 365 Apps for enterprise:
- Installs locally on the device
- Isn't web-only software
- Doesn't require constant Internet connectivity

This provides:
- Better performance
- Offline access
- Full desktop capabilities
