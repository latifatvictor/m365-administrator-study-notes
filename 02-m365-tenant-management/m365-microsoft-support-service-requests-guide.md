# 🚨 Microsoft Support Severity Levels

Microsoft assigns severity based on:
- Business impact
- Number of users affected
- Service availability

---

# 🔴 Severity A (Critical)

## Description
- One or more services unavailable
- Major production impact
- Multiple users affected

## Examples
- Exchange Online outage
- SharePoint site unavailable
- Teams messaging failure
- Users unable to send/receive mail

## Business Impact
- Severe operational disruption
- High urgency
- Immediate escalation required

---

# 🟠 Severity B (High)

## Description
- Service usable but impaired
- Moderate business impact
- Partial disruption

## Examples
- Outlook Send button broken
- Exchange Admin Center issue
- Performance degradation

## Business Impact
- Work continues with difficulty
- Often workaround available

---

# 🟡 Severity C (Noncritical)

## Description
- Minimal business impact
- Minor issue
- Workaround available

## Examples
- Password expiry configuration
- Unable to delete Exchange contact
- Minor configuration questions

# 📝 How to Submit a Service Request

## Steps

1. Open Microsoft 365 Admin Center
2. Select:
   Support → New Service Request
3. Complete required fields
4. Describe issue clearly
5. Submit request

---

# 📌 Best Practice for Service Requests

Always include:

- Tenant details
- Affected services
- Number of impacted users
- Error messages
- Screenshots
- Troubleshooting already completed
- Incident IDs (if applicable)
