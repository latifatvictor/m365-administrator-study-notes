# Monitor Tenant Health Using Microsoft 365 Adoption Score

---

# 📌 What is Microsoft 365 Adoption Score?

Microsoft Adoption Score is a Microsoft 365 feature that helps organizations measure:

- Digital transformation progress
- Microsoft 365 usage
- User adoption
- Technology health
- Productivity trends
- Collaboration effectiveness

It provides:
- Metrics
- Insights
- Recommendations
- Benchmarks

Organizations can compare their score against companies of similar size.

---

# 🎯 Main Purpose of Adoption Score

Adoption Score helps organizations:
- Improve Microsoft 365 usage
- Increase productivity
- Improve collaboration
- Enhance technology experiences
- Identify underused services
- Drive user adoption

---

# 📊 Two Main Areas Measured

## 1. People Experiences
Measures how users collaborate and work using Microsoft 365.

---

## 2. Technology Experiences
Measures device health, app performance, and connectivity quality.

# 📌 How Adoption Score Works

Microsoft collects:
- Organizational-level usage data
- Technology performance data
- Device analytics
- Collaboration activity

Important:
- Data is organizational level only
- No individual employee scoring

---

# 🧮 Maximum Adoption Score

Maximum possible score:
- 800 points total

Each category contributes:
- Up to 100 points

# ⚙️ How to Enable Adoption Score

## Steps

1. Sign into Microsoft 365 Admin Center
2. Navigate to:
   Reports → Adoption Score
3. Select:
   Turn on Adoption Score
4. Choose:
   Include all users
5. Save settings
