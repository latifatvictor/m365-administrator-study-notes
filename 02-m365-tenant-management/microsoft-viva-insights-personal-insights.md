# Explore Personal Insights in Microsoft Viva Insights

# Overview

Microsoft Viva Insights helps employees develop healthier and more productive work habits through personalised insights and recommendations.

Personal insights use Microsoft 365 collaboration data to help users:

- Improve productivity
- Build stronger work relationships
- Protect focus time
- Improve work-life balance
- Reduce burnout

---

# What Are Personal Insights?

Personal insights are private, user-specific analytics available within Microsoft Viva Insights.

These insights analyse workplace collaboration patterns using:

- Emails
- Meetings
- Calls
- Teams chats
- Calendar activity

The goal is to help users work more effectively and maintain wellbeing.

---

# Main Goals of Personal Insights

Microsoft Viva Insights Personal insights help users:

| Goal | Description |
|---|---|
| Strengthen work relationships | Maintain healthy collaboration |
| Increase focus time | Reduce distractions |
| Improve work-life balance | Reduce overload and burnout |
| Enhance wellbeing | Encourage healthy work habits |

---

# How Personal Insights Work

Personal insights analyse Microsoft 365 collaboration metadata and generate actionable recommendations.

These recommendations may include:

- Reserving focus time
- Taking regular breaks
- Reducing meeting overload
- Practicing mindfulness
- Improving collaboration habits

- OneDrive
- SharePoint

---

# Exchange Online Data

Personal insights analyse:

- Email metadata
- Calendar activity

---

## Email Data Used

| Data Type | Example |
|---|---|
| Timestamp | When email was sent |
| Sender/recipient | Email participants |
| Read status | Whether email was opened |
| Task statements | Commitments in emails |

---

# Important

Viva Insights analyses metadata and task-related patterns.

It does NOT expose private content to managers or administrators.

---

# Task Statements

Viva Insights can identify task-related phrases inside emails and generate personal task cards.

Examples:

- "I will send this tomorrow"
- "Can you complete this by Friday?"

These task cards are visible only to the user.

---

# Calendar Data Used

Viva Insights analyses:

| Calendar Data | Purpose |
|---|---|
| Meeting type | Meeting or appointment |
| Status | Busy, free, tentative |
| Duration | Meeting length |
| Attendees | Collaboration analysis |
| Subject | Meeting categorisation |

---

# Teams Data Used

Viva Insights counts:

- Audio calls
- Video calls
- Teams chats

as collaboration activities.

---

# OneDrive and SharePoint Data

Viva Insights tracks:

- Number of documents worked on
- Collaboration activity

---

# External User Data

Viva Insights generally does NOT process data from people outside the organisation.

However:

- Meeting metadata stored in your mailbox can still be analysed.

Example:

- External meeting start/end times

- Calendar information

---

# Privacy and Data Protection

Privacy is one of the most important principles of Personal insights.

---

# Key Privacy Principle

Only the user can see their personal insights.

---

# Important

Managers and administrators cannot access a user's personal insights data.

---

# What Viva Insights Does NOT Do

Viva Insights:

- Does not track employees
- Does not monitor screens
- Does not record keystrokes
- Does not install tracking software

---

# Important Statement

Microsoft Viva Insights does NOT have tracking software running on the computer.

---
