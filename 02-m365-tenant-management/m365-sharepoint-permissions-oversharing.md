# Manage SharePoint Permissions to Prevent Oversharing 

---

## 📌 What is Oversharing?

- Sharing data with more users than intended
- Can expose sensitive information
- Often caused by user behaviour

---

## ⚠️ Common Causes

- Saving files in public/shared locations
- Using broad groups instead of specific users
- Ignoring permissions when uploading files
- Using "Everyone Except External Users"
- Sharing via "Anyone" or org-wide links

---

## 🚨 Risk

- Sensitive data exposure
- Compliance violations
- Data leaks
- Tools like Copilot may surface overshared data

---

## 🎯 Goal

Ensure:
- Right users
- Right access
- Right content

---

## 🧠 Key Control Areas

---

### 1. Control Sharing Settings

- Review site-level sharing settings
- Remove "Everyone Except External Users"
- Restrict default sharing links (use "Specific people")

---

### 2. Use People Picker Carefully

- Tool used to assign permissions
- Avoid broad selections
- Encourage specific user/group selection

---

### 3. Educate Users

- Raise awareness of oversharing risks
- Promote best practices
- Encourage least privilege mindset

---

### 4. Manage Inactive Sites

- Identify unused sites
- Restrict access OR delete
- Reduce exposure surface

---

### 5. Monitor Oversharing Activity

Track:
- "Everyone Except External Users" usage
- Org-wide sharing links
- "Anyone" links

👉 Reports available (can export CSV or use Graph tools)

---

### 6. Remediate Oversharing

Actions:
- Restrict access to affected sites
- Remove unnecessary permissions
- Investigate via change history
- Work with site owners

---

### 7. Apply Access Controls

- Use Restricted Access Control policies
- Limit access to specific users only
- Apply to SharePoint & OneDrive

---

### 8. Protect Sensitive Data

- Block file downloads (where needed)
- Restrict Teams meeting recordings
- Apply encryption where required

---

## 💼 Real Work Scenario

Employee uploads HR file → shares with:
- "Everyone Except External Users"

Result:
- Entire company can access sensitive data

Fix:
- Remove broad access
- Share only with HR team

---

## 🔐 Best Practices

- Remove broad sharing options
- Use least privilege
- Default to "Specific people" sharing
- Regularly review permissions
- Monitor reports
- Restrict inactive sites
- Apply access policies to critical data

---

## 🎯 Interview Questions

Q1: What is oversharing?  
Giving access to more users than required

---

Broad permissions like "Everyone"

---

Restrict sharing + monitor + educate users

---

Tool to assign permissions

---

---

---

## 🧠 Summary

- Oversharing is a major security risk
- Caused by poor permission management
- Prevent with:
  - Controlled sharing
  - Monitoring
  - Access policies
  - User education
