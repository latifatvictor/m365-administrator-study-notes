# Examine the Analytical Features of Microsoft Viva Insights

# Overview

Microsoft Viva Insights is part of the Microsoft Viva employee experience platform.

Microsoft Viva integrates directly into:

- Microsoft Teams
- Microsoft 365
- Outlook
- Web applications

Viva Insights helps organisations improve:

- Productivity
- Employee wellbeing
- Collaboration
- Work culture
- Organisational effectiveness

using:

- Data-driven insights
- Privacy-protected analytics
- Workplace behaviour analysis

---

# What Is Microsoft Viva?

Microsoft Viva is an employee experience platform designed to bring together:

| Area | Purpose |
|---|---|
| Communications | Improve collaboration |
| Knowledge | Centralised information access |
| Learning | Employee growth |
| Resources | Organisational tools |
| Insights | Productivity and wellbeing analytics |

Viva integrates into apps employees already use daily.

# What Is Viva Insights?

Microsoft Viva Insights analyses Microsoft 365 collaboration data and organisational data to generate insights and recommendations.

These insights help:

- Employees
- Managers
- Business leaders
- Analysts

make informed decisions about:

- Productivity
- Work habits
- Burnout prevention
- Collaboration effectiveness
- Organisational resilience

---

1. Personal insights

# Privacy and Data Protection

Privacy is a major component of Viva Insights.

Microsoft designed Viva Insights with:

- De-identification
- Aggregation
- Metadata-only analysis
- Privacy protection controls

---

# How Viva Insights Processes Data

Viva Insights combines:

| Data Type | Source |
|---|---|
| Collaboration data | Microsoft 365 |
| Organisational data | HR systems |

---

# Collaboration Data

Collaboration data includes metadata such as:

- Email activity
- Meeting attendance
- Teams messages
- Calls
- Calendar activity

---

## Important

Viva Insights processes metadata only.

It does NOT analyse:

- Email content
- Chat content
- Attachments
- Document contents

---

# Examples of Metadata

| Metadata Example | Description |
|---|---|
| Sender/recipient | Email routing info |
| Subject line | Email subject |
| Meeting status | Accepted/declined |
| Timestamp | Date and time |

---

# Organisational Data

Organisational data comes from HR systems.

Examples include:

- Department
- Job title
- Region
- Manager hierarchy
- Business unit

---

# Why Organisational Data Matters

It helps analysts:

- Group employees
- Filter insights
- Compare departments
- Analyse behaviour trends

---

# Data Refresh Frequency

| Data Type | Refresh Frequency |
|---|---|
| Collaboration data | Weekly |
| HR data | Monthly or quarterly |

---

# Data Processing Flow

1. Microsoft 365 metadata collected
2. HR organisational data uploaded
3. Data joined together
4. Employee data de-identified
5. Behavioural metrics generated

---

# Privacy Protections

Microsoft uses:

- Data aggregation
- De-identification
- Access controls
- Role-based permissions

to protect employee privacy.

---

# Why Privacy Matters

Viva Insights contains potentially sensitive workplace behaviour data.

Improper use could expose:

- Employee productivity habits
- Work patterns
- Collaboration behaviour

Therefore organisations must:

- Respect privacy
- Follow regulations
- Use data ethically

---

# Viva Insights Roles

Microsoft Viva Insights uses role-based access control.

---

# 1. Insights Administrator

Responsible for:

- System configuration
- Privacy settings
- Data uploads
- Organisational data management

---

## Important

Insights Administrators are NOT automatically Microsoft 365 administrators.

They only access Viva organisational data unless assigned additional roles.

---

# 2. Insights Business Leader

Can view:

- Organisational dashboards
- Business insights
- Organisational trends

---

## Capabilities

- View My Organization dashboards
- Explore insights
- Review productivity metrics

---

# 3. People Manager

Can access:

- Team insights

Managers use these insights to understand team behaviours.

---

# 4. Analyst

Analysts have broad access to:

- Analysis workbench
- Query designer
- Reporting tools
- Advanced insights
- Plans

---

# 5. Analyst (Limited Access)

Limited analysts have:

- Read-only access to some settings
- No access to Query Designer

---

# 6. Program Manager

Program Managers help:

- Coordinate workplace improvement plans
- Manage organisational initiatives

---
