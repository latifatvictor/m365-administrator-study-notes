## Microsoft Purview – Data Governance & Compliance Summary

### Overview:
- Microsoft Purview is a **unified data governance and compliance platform**
- Helps organizations manage rapidly growing data across:
  - On-premises
  - Cloud
  - SaaS environments
- Addresses challenges like:
  - Data sprawl
  - Compliance risks
  - Lack of visibility into data

---

## Core Objectives:
1. **Preserve data** (retention & lifecycle management)  
2. **Discover & understand data** (classification & search)  
3. **Monitor & audit activity** (compliance & security)  

---

## Core Pillars:

### 1. Data Governance
- Manage data lifecycle:
  - Store, retain, archive, delete
- Apply policies across the organization
- Automate governance processes

---

### 2. eDiscovery
- Search and retrieve data quickly
- Support:
  - Legal investigations
  - Compliance requests

---

### 3. Auditing
- Track user and system activities
- Detect unusual or noncompliant behavior
- Support investigations and reporting

---

## Key Components:

### Data Map
- Central **metadata repository**
- Automatically scans and classifies data
- Keeps data inventory updated

---

### Data Catalog
- Enables users to:
  - Search and discover data
  - Understand context (labels, glossary)
- Shows **data lineage** (how data flows across systems)

---

### Data Estate Insights
- Provides **AI-driven visibility** into:
  - Data locations
  - Sensitive data
  - Data risks
- Helps ensure compliance (GDPR, HIPAA, etc.)

---

## Key Capabilities:
- Automated data discovery  
- Sensitive data classification  
- Data lineage tracking  
- Metadata indexing  
- Centralized data visibility  

---

## Challenges Solved:

### For Data Consumers:
- Easier data discovery  
- Clear understanding of data usage  
- Simplified access requests  

---

### For Data Producers:

- Easier data management and sharing  

---

### For Security Teams:

## Key Takeaway:
Microsoft Purview provides a **centralized, automated, and intelligent approach to data governance**, enabling organizations to **discover, manage, protect, and comply with regulations across their entire data estate**.
