## Plan Your Beginning Compliance Tasks in Microsoft Purview – Summary

### Overview:
This guide outlines the **essential first steps** to implement compliance in Microsoft Purview, focusing on:
- Managing and monitoring data  
- Protecting sensitive information  
- Reducing risks (including insider risks)  

---

## Task 1: Configure Compliance Permissions
- Assign roles to control access to compliance tools:
  - **Compliance Administrator**
  - **Compliance Data Administrator**
  - **Global Reader** (for Compliance Manager visibility)
- ✅ Ensures:
  - Proper access control  
  - Reduced risk of unauthorized actions  

---

## Task 2: Assess Your Compliance Posture
- Use **Compliance Manager** to:
  - Measure compliance score  
  - Identify gaps and risks  
  - Track improvement actions  

✅ Key benefit:
- Understand current compliance state before making changes  

---

## Task 3: Enable Auditing
- Turn on **audit logging** to track:
  - User activities  
  - Admin actions  
- Retention:
  - Default: **180 days**
  - Up to **1 year** (depending on licensing)

✅ Required for:
- Investigations  
- Reporting  
- Forensic analysis  

---

## Task 4: Configure Alert Policies
- Use built-in alerts for:
  - Admin misuse  
  - Malware activity  
  - Data loss incidents  
- Create **custom alerts** for specific needs

✅ Helps:
- Detect compliance violations early  
- Monitor risky activity  

---

## Task 5: Classify & Protect Sensitive Data
- Use **Sensitivity Labels** to:
  - Encrypt data  
  - Restrict access  
  - Apply visual markings  

✅ Protects data across:
- Email  
- Documents  
- Cloud apps  
- Devices  

---

## Task 6: Configure Retention Policies
- Define lifecycle rules:
  - Retain data  
  - Delete data  
  - Retain then delete  

- Apply across:
  - Exchange  
  - SharePoint  
  - OneDrive  
  - Teams  

- Use:
  - **Adaptive scope** (dynamic targeting)  
  - **Static scope** (manual targeting)  

✅ Ensures compliance & reduces risk  

---

## Task 7: Configure Communication Compliance
- Detect and manage risks such as:
  - Harassment or abusive language  
  - Sharing sensitive information  
- Use built-in templates:
  - Offensive language policies  
  - Sensitive information policies  

✅ Enables:
- Monitoring communications  
- Investigating violations  
- Taking corrective actions  

---

## Task 8: Monitor Sensitive Data Activity

### Content Explorer:
- View:
  - Labeled items  
  - Classified data  
- Inspect actual content  

---

### Activity Explorer:
- Track user actions on sensitive data:
  - Access  
  - Sharing  
  - Modifications  

✅ Provides visibility into:
- Data usage  
- Potential risks  

---

## Key Takeaway:
Start with **permissions, visibility, and data protection**, then move to **policies and monitoring**. These foundational steps ensure your organization can:
- ✅ Understand compliance risks  
- ✅ Protect sensitive data  
- ✅ Monitor and respond to threats  
- ✅ Maintain regulatory compliance effectively
