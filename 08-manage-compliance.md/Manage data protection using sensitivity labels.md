## Sensitivity Labels in Microsoft Purview – Summary

### Overview:
- **Sensitivity labels** are used to:
  - ✅ Classify data  
  - ✅ Protect content based on sensitivity  

👉 They act like a **digital “stamp”** on documents and emails:
- Example:
  - Public  
  - Internal  
  - Confidential  
  - Highly Confidential  

---

## What Sensitivity Labels Do:

### 1. Classify Data
- Indicate how sensitive information is  
- Help users understand:
  - How to handle data  

---

### 2. Protect Data
Labels can automatically apply protections like:
- 🔐 Encryption  
- 🚫 Access restrictions  
- 💧 Watermarks  
- 🏷️ Headers and footers  

---

### 3. Govern Data
- Control:
  - Sharing  
  - Usage  
  - Retention  

---

## How Labels Are Applied:

### 1. Manual (User-Driven)
- Users select labels in:
  - Word, Excel, PowerPoint, Outlook  
- Example:
  - Mark document as “Confidential”  

---

### 2. Automatic (Policy-Based)
- Applied based on:
  - Content (e.g., credit card data)  
  - Location (e.g., SharePoint site)  
  - User or group  

---

### 3. Recommended Labels (AI-Assisted)
- System suggests label:
  - Based on content analysis  
- User decides:
  - Accept or reject  

---

## Key Capabilities:

---

### 🔐 Encryption & Protection
- Automatically encrypt sensitive content  
- Restrict actions:
  - View  
  - Edit  
  - Print  
  - Share  

---

### 💧 Content Markings
- Add:
  - Watermarks  
  - Headers  
  - Footers  

---

### 🌐 Cross-Platform Protection
- Works across:
  - Office apps (desktop & web)  
  - Windows, macOS, iOS, Android  

---

### ☁️ Third-Party Protection
- Protect content in:
  - Dropbox  
  - Salesforce  
  - Box  
- Via:
  - Microsoft Defender for Cloud Apps  

---

### 🏢 Container Protection
- Apply labels to:
  - Teams  
  - SharePoint sites  
  - Microsoft 365 Groups  

---

#### Controls include:
- External sharing  
- Access permissions  
- Device restrictions  

---

### 🏷️ Classification Only Mode
- Labels used:
  - Without protection  
- Benefits:
  - Visibility  
  - Reporting  
- Can add protections later  

---

## Sensitivity Labels Characteristics:

---

### ✅ Customizable
- Designed for your business needs  
- Example levels:
  - General  
  - Confidential  
  - Highly Confidential  

---

### ✅ Persistent
- Label stays with file:
  - Even when copied/shared  

---

### ✅ Stored in Metadata
- Saved as:
  - Clear text tag  
- Allows:
  - Integration with third-party apps  

---

### ✅ Single Label per Item
- Each document/email:
  - Only **one sensitivity label**  
- Can also have:
  - ✅ Retention label alongside it  

---

## Where You See Labels:
- Office apps (Ribbon / status bar)  
- Email messages  
- SharePoint / OneDrive files  
- Teams documents  

---

## Extended Integrations:

### 📊 Power BI
- Apply labels to reports  
- Protect exported data  

---

### ☁️ Azure (Purview)
- Label:
  - SQL data  
  - Blob storage  
  - Cloud assets  

---

### 🔗 Third-Party Apps
- Use:
  - Microsoft Information Protection SDK  
- Enables:
  - Label-aware protection

## Example Scenario:

### Situation:
- User creates document with financial data  

---

### Label Applied:
- “Highly Confidential”  

---

### Result:
- 🔐 File is encrypted  
- 🚫 External sharing blocked  
- 💧 Watermark applied  
- 👁️ Access limited to specific users  

---

## Benefits:

- ✅ Protect sensitive data automatically  
- ✅ Ensure compliance with regulations  
- ✅ Reduce accidental data sharing  
- ✅ Provide consistent data handling rules  
- ✅ Enable visibility and tracking  

---

## Best Practices:
- ✅ Start with simple label structure (3–5 levels)  
- ✅ Use clear, meaningful names  
- ✅ Combine classification + protection  
- ✅ Enable auto-labeling where appropriate  
- ✅ Train users on label usage  
- ✅ Monitor adoption and refine  

---

## Key Takeaway:
Sensitivity labels are a **core data protection mechanism** in Microsoft Purview that:

- Classify content  
- Apply automated protections  
- Persist with data wherever it goes  

➡️ Helping organizations **secure, govern, and control sensitive information across Microsoft 365 and beyond**
