# Examine Account Breaches

## Overview

An account breach occurs when unauthorized individuals gain access to a user account. Attackers use various techniques to compromise credentials, steal sensitive information, escalate privileges, and access organizational resources. Account breaches often begin with stolen credentials obtained through phishing, password attacks, credential stuffing, or social engineering. Organizations can significantly reduce risk by implementing MFA, strong security policies, user education, monitoring, and modern identity protection solutions like Microsoft Entra ID Protection.

Account breaches can result in:
- Data theft
- Identity theft
- Financial loss
- Privacy violations
- Unauthorized system access
- Further cyberattacks

---

# Common Methods Used to Breach Accounts

Attackers commonly compromise accounts through:

- Password attacks
- Phishing
- Credential stuffing
- Key loggers
- Social engineering

---

# Password Attacks

Password attacks occur when attackers attempt to guess or steal passwords.

Common password attack methods include:

- Brute force attacks
- Password spraying
- Dictionary attacks
- Exploiting weak passwords
- Reused passwords

---

# Brute Force Attacks

Brute force attacks involve:
- Systematically trying multiple password combinations until the correct password is found.

Attackers often target:
- Weak passwords
- Short passwords
- Common passwords

---

# Weak Password Risks

Weak passwords are:
- Easy to guess
- Commonly reused
- Predictable

Examples include:
- Password123
- CompanyName2026
- Admin123

---

# Phishing Attacks

Phishing attacks trick users into revealing:

- Usernames
- Passwords
- Credit card information
- Sensitive company data

Attackers impersonate:
- Banks
- IT administrators
- Trusted organizations
- Microsoft services

---

# Credential Stuffing

Credential stuffing occurs when attackers:

1. Obtain usernames and passwords from previous breaches.
2. Attempt to use the same credentials on other services.

This attack succeeds because:
- Many users reuse passwords across multiple accounts.

---

# Key Loggers

A key logger is:
- Malware or hardware that records keystrokes secretly.

Key loggers capture:
- Passwords
- Credit card numbers
- Messages
- Sensitive information

---

# How Key Loggers Work

Key loggers:
1. Install on a device.
2. Monitor keyboard input.
3. Record keystrokes.
4. Send captured information to attackers.

---

# Social Engineering

Social engineering manipulates users into revealing confidential information.

Attackers may:
- Pretend to be trusted individuals
- Create fake emergencies
- Exploit fear or urgency
- Convince users to disclose credentials willingly

---

# Effects of Account Breaches

Once attackers gain access to an account, they may:

- Read emails
- Access files
- Steal sensitive information
- Send messages as the user
- Escalate privileges
- Spread malware
- Access additional systems

---

# Administrative Account Breaches

Administrative account breaches are especially dangerous because attackers can:

- Access critical systems
- Modify configurations
- Create new accounts
- Disable security tools
- Move laterally across the network
