# Track Your Microsoft Secure Score History and Meet Your Goals

## Overview

Microsoft Secure Score helps organizations:
- Measure security posture
- Monitor security improvements
- Track historical security trends
- Compare against similar organizations
- Set long-term security goals

A higher Secure Score indicates:
- More security recommendations implemented
- Better protection against threats
- Stronger Microsoft 365 security posture

---

# History Tab

The History tab allows organizations to:
- View Secure Score changes over time
- Monitor completed actions
- Review score progression
- Track configuration changes

The History tab displays:
- Score history graph
- Recommended actions completed
- Resulting score changes
- Categories impacted
- Timeline of security improvements

Organizations can:
- Customize date ranges
- Filter by category
- Review historical activities

---

# Viewing Recommended Action History

Selecting a recommended action opens:
- The detailed action flyout

The flyout provides:
- Security details
- Configuration information
- Historical changes

Selecting the:
"History" link

Shows:
- All historical activity for that recommendation

---

# Metrics and Trends Tab

The Metrics and trends tab provides:
- Security analytics
- Trend visualizations
- Goal tracking
- Benchmark comparisons

Organizations can:
- Set custom date ranges
- Analyze security trends
- Monitor progress over time

---

# Visualizations Available

Microsoft Secure Score provides several important visualizations.

---

# Your Secure Score Zone

## Purpose

Displays:
- Security posture ranges

Organizations can define:
- Good score ranges
- Acceptable score ranges
- Poor score ranges

This helps organizations:
- Set measurable security goals
- Evaluate current posture

---

# Regression Trend

## Purpose

Displays:
- Security score decreases over time

Regression occurs due to:
- Configuration changes
- User changes
- Device changes
- Security control removal

This helps organizations:
- Detect weakened security posture
- Identify accidental regressions

---

# Comparison Trend

## Purpose

Shows:
- How the organization compares to similar organizations over time

Comparison can include:
- Similar organization seat counts
- Custom comparison groups

Benefits:
- Benchmarking
- Security maturity comparison
- Progress evaluation

---

# Risk Acceptance Trend

## Purpose

Tracks:
- Recommended actions marked as:
  "Risk accepted"

This helps organizations:
- Monitor accepted risks
- Understand long-term exposure

---

# Score Changes

## Purpose

Displays:
- Points achieved
- Points regressed
- Total score changes

This helps organizations:
- Measure security improvement
- Track remediation efforts

---

# Comparison Bar Chart

The Comparison bar chart appears on:
- The Overview tab

It allows organizations to:
- Compare Secure Score against similar organizations

The chart displays:
- Organization score
- Average peer score
- Score opportunity

---

# Important Note About Comparison Data

Comparison data is:
- Anonymous

Microsoft:
- Does NOT identify specific tenants included in comparisons

---

# Comparison Trend Graph

The Comparison trend graph appears in:
- Metrics and trends tab

It displays:
- Secure Score comparison over time

Organizations can:
- Monitor progress against peers
- Identify improvement opportunities

# Important Security Concepts

## Regression

Regression means:
- Security posture weakened over time

Causes include:
- Disabled controls
- Removed protections
- New vulnerabilities
- Misconfigurations

---

# Benchmarking

Benchmarking helps organizations:
- Compare against peers
- Evaluate security maturity
- Identify gaps

---

# Risk Acceptance

Risk acceptance means:
- Organization intentionally accepts a security risk
- Recommendation remains unimplemented

Reasons may include:
- Business limitations
- User productivity concerns
- Technical constraints
