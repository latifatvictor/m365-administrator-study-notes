# Assess Your Security Posture with Microsoft Secure Score

## Overview

Microsoft Secure Score is a measurement of an organization’s security posture.

A higher Secure Score means:
- More security recommendations were implemented
- Better protection against threats
- Improved security configuration across Microsoft 365

Microsoft Secure Score helps organizations:
- Monitor security posture
- Prioritize security improvements
- Compare against benchmarks
- Track progress over time

---

# Secure Score Recommendation Categories

Microsoft Secure Score organizes recommendations into four major groups.

| Category | Description |
|---|---|
| Identity | Microsoft Entra accounts and roles |
| Device | Microsoft Defender for Endpoint |
| Apps | Email and cloud app security |
| Data | Microsoft Purview Information Protection |

---

# Identity Category

# Checking Your Current Score

To view the current Secure Score:

1. Open Microsoft Secure Score
2. Go to the Overview tab
3. Locate the:
   "Your secure score" tile

The tile displays:
- Percentage score
- Achieved points
- Total possible points

Example:
- 245 / 400 points
- 61%

---

# Score Views

Microsoft Secure Score provides multiple score perspectives.

---

# Planned Score

## Definition

Shows:
- Projected score after completing planned actions

Purpose:
- Helps organizations estimate future improvements

---

# Current License Score

## Definition

Shows:
- Maximum score achievable with current Microsoft licenses

Purpose:
- Helps organizations understand licensing limitations

---

# Achievable Score

## Definition

Shows:
- Maximum realistic score based on:
  - Current licenses
  - Accepted risks
  - Existing environment

Purpose:
- Helps organizations identify realistic security goals

# Important Concepts

## Higher Score = Better Security Posture

A higher score generally means:
- More security controls implemented
- Better protection against threats
- Reduced risk exposure

However:
- Secure Score is NOT a guarantee against attacks
