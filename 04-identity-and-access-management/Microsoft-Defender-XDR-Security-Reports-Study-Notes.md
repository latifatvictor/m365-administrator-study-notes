# Review the Security Reports in Microsoft Defender XDR

## Overview

Microsoft Defender XDR provides:
- Centralized security reporting
- Security monitoring
- Threat visibility
- Protection status tracking

The Microsoft Defender portal organizes reports into three main categories:

1. Security
2. Email and collaboration
3. Endpoints

---

# Main Report Categories

## Security Reports

Security reports help organizations:
- Monitor security trends
- Track protection status
- Review organizational security posture

Security reports focus on:
- Identities
- Data
- Devices
- Applications

---

# Email and Collaboration Reports

Email and collaboration reports help organizations:
- Improve email security
- Monitor mail protection
- Review collaboration security recommendations

---

# Endpoint Reports

Endpoint reports help organizations:
- Monitor device health
- Track vulnerabilities
- Review malware detections
- Analyze web protection

---

# Required Roles to Access Reports

To view reports in Microsoft Defender portal, users must belong to one of these roles:

- Organization Management
- Security Administrator
- Security Reader
- Global Reader

---

# Microsoft Entra Role Integration

Adding users to Microsoft Entra roles in the Microsoft 365 admin center:
- Grants permissions in Microsoft Defender portal
- Enables access to Microsoft 365 security features
