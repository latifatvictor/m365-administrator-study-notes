# Protect Against Cyber Attacks Using Microsoft 365 Threat Intelligence

## Overview

Microsoft 365 Threat Intelligence is:
- A cloud-based security service
- Designed to provide visibility into the global threat landscape
- Used to deliver actionable cybersecurity insights
- Used to help organizations proactively defend against cyber attacks



---

# Main Purpose of Microsoft 365 Threat Intelligence

Microsoft 365 Threat Intelligence helps organizations:

- Detect threats proactively
- Respond to cyber attacks
- Analyze threat activity
- Gain visibility into attacker behavior
- Improve cybersecurity decisions

---

# Microsoft 365 Threat Intelligence Licensing

## Availability

Microsoft 365 Threat Intelligence is included with:
- Microsoft 365 Enterprise E5

Organizations with other Microsoft 365 Enterprise subscriptions can:
- Purchase Threat Intelligence as an add-on

---

# Integration with Microsoft Security Services

Microsoft 365 Threat Intelligence integrates with:
- Exchange Online Protection (EOP)
- Microsoft Defender for Office 365
- Microsoft Intelligent Security Graph
