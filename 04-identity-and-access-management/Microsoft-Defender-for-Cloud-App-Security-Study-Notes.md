# Provide Insight Into Suspicious Activity Using Microsoft Defender for Cloud App Security

## Overview

Microsoft Defender for Cloud App Security:
- Provides visibility into suspicious activities in Microsoft 365
- Helps organizations monitor cloud applications
- Improves security control over cloud environments
- Enhances visibility into cloud usage and threats



---

# Core Areas of Cloud App Security

Cloud App Security consists of three main areas:

1. Threat detection
2. Enhanced control
3. Discovery and insights

---

# Threat Detection

## Overview

Threat detection helps organizations:
- Identify abnormal activity
- Detect security incidents
- Detect high-risk behavior
- Identify cyber threats

---

# Threat Detection Example

Example:
- An administrator forwards mail unusually
- Cloud App Security detects abnormal behavior
- An alert email is generated
- Security teams can investigate immediately

---

# Enhanced Control

## Overview

Enhanced control enables organizations to:
- Monitor activities
- Apply granular policies
- Respond to suspicious actions

---

# Enhanced Control Example

Example:
- A user performs a mass download of files

- Administrators can investigate and respond

It helps organizations:

- Govern cloud applications
- Discover Shadow IT
- Maintain compliance

Core strengths include:
- Threat detection
- Real-time monitoring
- Cloud discovery
- Policy enforcement
- Compliance management
- Cloud visibility

Cloud App Security enables organizations to:
- Balance cloud flexibility with security
- Improve cloud governance
- Reduce cyber risks
- Protect data across Microsoft and third-party cloud apps
