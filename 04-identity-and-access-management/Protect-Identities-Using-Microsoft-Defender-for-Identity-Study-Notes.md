# Protect Your Organization's Identities Using Microsoft Defender for Identity

## Overview

Microsoft Defender for Identity:
- Is a cloud-based security solution
- Was formerly known as Azure Advanced Threat Protection (Azure ATP)
- Uses signals from on-premises Active Directory environments

Its purpose is to:
- Detect advanced threats
- Identify compromised identities
- Investigate malicious insider activity
- Protect hybrid identity environments


---

# Main Goals of Microsoft Defender for Identity

Defender for Identity helps security teams:

- Monitor users and entities
- Detect suspicious behavior
- Protect credentials
- Investigate advanced attacks
- Analyze incidents quickly
- Reduce organizational attack surface

---

# Defender for Identity Detection Stages

## 1. Reconnaissance

### Purpose

Detects attackers gathering information.

---

# Reconnaissance Activities

Examples include:
- User enumeration
- Group membership discovery
- IP address discovery
- Resource identification

---

# 2. Compromised Credentials

## Purpose

Detects credential compromise attempts.

---

# Examples

Includes:
- Brute-force attacks
- Failed authentications
- Suspicious group changes
- Credential theft attempts

---

# 3. Lateral Movement

## Purpose

Detects attackers moving through the network.

---

# Common Lateral Movement Techniques

Includes:
- Pass the Ticket
- Pass the Hash
- Overpass the Hash

---

# Goal of Lateral Movement

Attackers attempt to:
- Gain additional privileges
- Reach sensitive systems
- Access high-value accounts

---

# 4. Domain Dominance

## Purpose

Detects attacks targeting domain-wide control.

---

# Domain Dominance Techniques

Includes:
- Remote code execution on domain controllers
- DC Shadow attacks
- Malicious replication
- Golden Ticket attacks

---

# Golden Ticket Attacks

Golden Ticket attacks:
- Forge Kerberos tickets
- Allow persistent privileged access
