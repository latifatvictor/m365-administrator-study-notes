# Plan for a Zero Trust Security Model in Your Organization

## Overview

Zero Trust is a modern security strategy based on:

Never trust, always verify

Organizations should assume:
- Every request could be malicious
- Every device could be compromised
- Every session requires verification

Zero Trust moves organizations away from implicit trust and towards explicit verification.

---

# Five Steps to Secure Identity Infrastructure

1. Strengthen credentials
2. Reduce attack surface
3. Automate threat response
4. Increase awareness
5. Enable user self-help

---

# Strengthen Credentials

Organizations should:
- Enforce strong passwords
- Enable MFA
- Reduce password reuse
- Monitor risky sign-ins

MFA helps protect against:
- Phishing
- Password spraying
- Credential stuffing
- Stolen passwords

---

# Reduce Attack Surface

Organizations should:
- Disable legacy authentication
- Restrict administrative access
- Limit entry points
- Remove unused services
- Apply least privilege access

---

# Automate Threat Response

Automation helps:
- Reduce response time
- Lower risk
- Reduce manual effort

Examples include:
- Requiring MFA
- Blocking access
- Forcing password reset
- Isolating risky devices

---

# Increase Awareness

Organizations should use:
- Auditing
- Logging
- Alerts
- Threat analytics

This helps detect:
- Suspicious behaviour
- Internal attacks
- External compromise attempts

---

# Enable User Self-Help

Organizations can reduce friction by enabling:
- Self-service password reset
- Secure self-service recovery
- User-friendly authentication options

---

# Move from Implicit Trust to Explicit Verification

Zero Trust requires organizations to explicitly verify:
- Authentication claims
- Device health
- Application usage
- Data sensitivity
- Session risk

---

# Full Session Context

A strong Zero Trust strategy evaluates:
- User identity
- Device state
- Apps being used
- Sensitivity of data
- Risk signals
- Session behaviour

---

# Holistic Access Policies

Zero Trust policies decide whether to:
- Allow access
- Block access
- Restrict access

Controls may include:
- Multifactor authentication
- Download restrictions
- Terms of use
- Device compliance checks
- Session limitations

Conditional Access can evaluate:
- User risk
- Sign-in risk
- Device compliance
- Location
- Session behaviour

It can then:
- Require MFA
- Block access
- Require compliant devices
- Limit session actions

---

# Key Takeaway

Zero Trust replaces the assumption that internal users and devices are safe with continuous explicit verification. Organizations must authenticate users, validate devices, classify data, monitor risk, and apply adaptive security policies before granting access.
