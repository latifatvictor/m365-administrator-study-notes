# Protect Your Enterprise Network Against Advanced Threats Using Microsoft Defender for Endpoint

## Overview

Microsoft Defender for Endpoint is:
- An enterprise endpoint security platform
- Designed to help organizations:
  - Prevent attacks
  - Detect threats
  - Investigate incidents
  - Respond to advanced cyber threats

It combines:
- Windows 10 and Windows 11 built-in technologies
- Microsoft's cloud security services



---

# Core Technologies Used by Microsoft Defender for Endpoint

Microsoft Defender for Endpoint uses:

1. Endpoint behavioral sensors
2. Cloud security analytics
3. Threat intelligence
