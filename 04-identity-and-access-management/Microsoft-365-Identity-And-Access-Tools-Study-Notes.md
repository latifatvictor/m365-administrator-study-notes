# Examine the Identity and Access Tools Used in Microsoft 365

## Overview

Identity and access management (IAM) is a critical component of Microsoft 365 security. It ensures:
- Only authorized users can access resources
- Secure authentication and authorization
- Consistent policy enforcement
- Protection of cloud and on-premises environments

Microsoft 365 provides several identity and access tools, including:
- Microsoft Entra ID
- Microsoft 365 admin center
- Single Sign-On (SSO)
- PowerShell for Microsoft 365
- Microsoft Graph API

# Microsoft Entra ID

## What is Microsoft Entra ID?

Microsoft Entra ID is:
- A cloud-based identity and directory service
- Microsoft’s identity and access management platform
- Used for Microsoft 365 and other cloud applications

It enables:
- Secure authentication
- User identity management
- Access management across services
